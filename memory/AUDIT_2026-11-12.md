# Code audit, 12 Nov 2026 (branch audit-fixes)

## Findings
1. BUG (since v1.1): OppModel.observe_hand recorded OUR bet sizes in the wrong
   response bucket (operator precedence reset button bets to 1/2 on every
   street, and the pot formula subtracted our bet). Fold/call/raise rates per
   size were mixed up. Fixed; switch FIX_BUCKET.
2. DEAD PARAMS: VALUE_MIN and BLUFF_SCALE are not read anywhere; STACK_OFF_EQ
   was read from CFG, not PARAMS. Stage A trained them for nothing. STACK_OFF_EQ
   is now read from PARAMS; Stage A trains UNCERTAINTY and OOP_PENALTY instead.
3. Flop showdown strength (Fix A learning) used the turn card, or card 51 as a
   placeholder. Now uses the flop only.
4. BB 3-bet width never widened vs wide openers (min(PF_3BET_Q, 0.3 x pfr)).
   Now PF_3BET_Q x clamp(pfr / 0.45, 0.5, 2.0); switch PF_3BET_SCALE.
5. Bet EV assumed we always fold when raised (RAISE_EV). Implemented, OFF by
   default: hurt vs gto_like in combination with the bucket fix.
6. Range narrowing learns bet meaning only from showdowns (selection bias vs
   aggressive bots). A betting-frequency floor (USE_FREQ_FLOOR) was tried:
   size-blind version lost badly to friend (honest big bets, frequent bets);
   per-size version neutral. OFF by default.
